ER Diagram ฉบับรวมก่อนปรับปรุง (Unadjusted Hospital ER Diagram - BEFORE)

สภาพก่อนรวมระบบ: แต่ละแผนกพัฒนาฐานข้อมูลแบบ Data Silos ขาด Foreign Key เชื่อมโยง ข้อมูลซ้ำซ้อน และโครงสร้างขัดแย้ง 1NF/2NF

[!] Data Type ขัดแย้ง (String vs Int)
[!] ไร้ FK เชื่อมระหว่าง OPD กับการเงิน
[!] ขาด FK Constraint / เสี่ยง Orphan Data
[!] ยาหลายตัวในบิลเดียว ไร้ตารางกลาง (1NF)
[!] ข้อมูลคนไข้ซ้ำซ้อน เสี่ยง Update Anomaly
[!] แพทย์บันทึกเป็น Free-text ไร้ FK อ้างอิง H7
H1: patients (ระบบผู้ป่วย) 1NF / 2NF Violation
[PK] patient_id (VARCHAR)
first_name, last_name
• phone, email (เก็บรวมในฟิลด์เดียว ขัด 1NF)
• insurance_name, policy_no (เก็บรวมในตาราง ขัด 2NF)
blood_group, weight, height
H2: appointments (ระบบนัดหมาย) Redundant PII
[PK] appointment_id (INT)
• patient_id (INTEGER - ไม่ตรงกับ VARCHAR ของ H1)
• patient_name (เก็บชื่อคนไข้ซ้ำซ้อน เสี่ยงข้อมูลไม่ตรงกัน)
• patient_phone (เก็บเบอร์โทรศัพท์ซ้ำซ้อน)
appointment_date, appointment_time
H3: billing (ระบบการเงิน) No Foreign Key
[PK] bill_id (SERIAL)
• patient_name (พิมพ์ชื่อคนไข้เอง ไร้ FK อ้างอิง H1)
• insurance_company (ข้อความ Free-text สะกดเพี้ยน)
total_amount, payment_status
• amount_paid (ไม่รองรับการแบ่งจ่ายประกัน Split Bill)
H4: prescriptions (ระบบยา) Unresolved M:N
[PK] rx_id (VARCHAR)
• patient_id (ไม่มี Foreign Key ผูกกับ H1)
doctor_id
• medication_list (เก็บยาคั่นด้วยจุลภาค Comma-separated)
• ความสัมพันธ์ M:N ระหว่างใบสั่งยาและยายังไม่ถูกแยกตาราง
H5: lab_requests (ระบบแล็บ) Missing Doctor FK
[PK] lab_no (VARCHAR)
• patient_id (ไม่มี Foreign Key ผูกกับ H1)
• doctor_name (บันทึกชื่อแพทย์เป็นตัวอักษร ไม่ผูก FK กับ H7)
test_type, result_value
• ไม่สามารถตรวจสอบย้อนกลับ (Traceability) หาผู้ตรวจได้
H6: admissions (ระบบผู้ป่วยใน) Lost History (H03)
[PK] admission_id (VARCHAR)
patient_id, bed_id
• patient_name, contact_phone (เก็บซ้ำกับ H1)
• doctors (มีแพทย์ดูแลร่วมหลายคนแต่มีฟิลด์เดียว ขัด H01)
• ย้ายเตียงแล้วเขียนทับเตียงเดิม (สูญเสียประวัติ ขัด H03)
H7: doctors (ระบบบุคลากร) 2NF / H05 Violation
[PK] doctor_id (VARCHAR)
• doctor_name, department_name (ไม่มีตารางแผนกแยก ขัด 3NF)
• ไม่บันทึกประวัติการย้ายแผนกของแพทย์ (ขัด Change Card H05)
specialty, email, salary_thb
